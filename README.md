# ✦ DreamKit

### Beautiful animated UI components for modern websites.

DreamKit is an open-source collection of animated and interactive UI components built for modern web projects.

**Copy. Paste. Customize. Ship.**

No complicated setup. No unnecessary dependencies. Just beautiful components you can use in your projects.

---

## ✨ What is DreamKit?

DreamKit is a growing collection of reusable UI components designed for developers who want to build modern, interactive and visually impressive websites without creating every animation from scratch.

The library currently includes components for:

* 🎨 Backgrounds
* 🔘 Buttons
* 🃏 Cards
* 🖱️ Cursor effects
* 🦸 Hero sections
* ⏳ Loaders
* 📊 Progress components
* and more

New components are being added continuously.

## 🚀 Get Started

The easiest way to use DreamKit is through the official website.

**→ Visit DreamKit**

Browse the component library, preview components live, and copy the code you need directly into your project.

### How it works

**1. Explore**
Find a component you like on the DreamKit website.

**2. Preview**
See how it looks and interacts in real time.

**3. Copy**
Copy the component source directly from the component page.

**4. Customize**
Adapt the component to your project and make it your own.

**5. Ship**
Drop it into your project and build something great.

> No need to clone the entire DreamKit repository.

## 💡 Using Components

Choose a component from the DreamKit website and copy its source code into your project.
